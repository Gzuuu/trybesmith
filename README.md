# Trybesmith

## 📖 Descrição Breve

O **Trybesmith** é um projeto desenvolvido com **TypeScript**, sendo o primeiro contato com essa tecnologia. Ele expande o aprendizado de bancos de dados, agora com a integração do **Sequelize** e aplicação de tipagem estática. O tema do projeto é um "ferreiro", onde é possível gerenciar produtos, usuários e pedidos.

## 💻 Como Rodar o Projeto

1. Clone o repositório:
   ```bash
   git clone https://github.com/Gzuuu/trybesmith.git
   ```
2. Entre na pasta do projeto:
   ```bash
   cd trybesmith
   ```
3. Instale as dependências:
   ```bash
   npm install
   ```
4. Certifique-se de que o Docker está instalado e execute:
   ```bash
   docker compose up
   ```
5. Inicie o servidor:
   ```bash
   npm start
   ```
6. Acesse em `http://localhost:3001` via navegador, ThunderClient ou Postman.

## 🛠️ Tecnologias Utilizadas

- **TypeScript**
- **Node.js**
- **Express**
- **Sequelize**
- **MySQL**
- **Docker**
- **Postman/ThunderClient**

## 🌟 Funcionalidades

- Criação e gerenciamento de **produtos**, **usuários** e **pedidos**.
- Uso do **Sequelize** para modelagem e interação com o banco de dados.
- Aplicação de **tipagem estática** com TypeScript para maior confiabilidade do código.

## 🚀 Aprendizados Principais

- Primeiros passos com **TypeScript** e suas vantagens.
- Uso do **Sequelize** para abstração de banco de dados.
- Organização do código com boas práticas e tipagem.
- Configuração e execução de ambientes com **Docker**.
